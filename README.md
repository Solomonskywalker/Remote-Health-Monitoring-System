Remote Health Monitoring System

Overview

The Remote Health Monitoring System (RHMS) is a Java-based healthcare application designed to support remote monitoring of patient health information and improve communication between patients and healthcare professionals.

The project was developed as part of a Software Engineering foundation course and demonstrates object-oriented programming principles, software design methodologies, and healthcare information management concepts.

---

Project Objectives

The primary goal of the system is to provide a platform for:

- Managing patient health information
- Monitoring health-related data remotely
- Facilitating interaction between patients and healthcare providers
- Improving access to healthcare information

---

Features

- Patient management
- Doctor management
- Health data recording
- Feedback management
- Health information tracking
- Basic healthcare record management
